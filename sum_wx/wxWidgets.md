# Elixir + wxWidgets ミニアプリ計画

## 目的
Elixir で `:wx`（Erlang/OTP 同梱の wxWidgets バインディング）を使い、
`テキストボックス + テキストボックス = ラベル` を表示する最小限 GUI アプリを作る。

## 実装方針
1. **新規 Mix プロジェクトを作成**
   - `mix new` で雛形作成。
   - 依存追加は不要（`:wx` は OTP に含まれるため）。

2. **GUI モジュールを作成**
   - `:wx.new()` で初期化。
   - フレーム、パネル、2つのテキスト入力、`+` ラベル、`=` ラベル、結果ラベルを生成。
   - 横並びレイアウト（sizer）で最小 UI を構成。

3. **イベント処理を実装**
   - 2つのテキストボックスの変更イベントを受ける。
   - 入力値を整数として解釈して合計を計算。
   - 結果ラベルを都度更新。
   - 空文字や数値以外は `0` 扱いなどシンプルに定義。

4. **アプリ起動エントリを整備**
   - `mix run -e` で起動できるよう公開関数（例: `start/0`）を用意。
   - GUI イベントループを維持し、ウィンドウを閉じたら終了。

5. **動作確認**
   - 起動確認。
   - 数値入力時にリアルタイムで結果が更新されることを確認。
   - 異常入力時の挙動（0扱い）を確認。

## 成果物（予定）
- Mix プロジェクト一式
- `:wx` を使った最小 GUI 実装コード
- 実行手順（`mix run ...`）

## 次ステップ
この計画に沿って、実際のプロジェクト作成とコード実装に進む。

## 新規プロジェクトのハーネス導入

`mix new` 直後に、次を実行すると `mix qa` ハーネスを自動導入できます。

```bash
./scripts/setup_elixir_harness.sh <mix_project_dir>
```

例:

```bash
mix new sample_app
./scripts/setup_elixir_harness.sh sample_app
cd sample_app
mix qa
```
